# AI-Powered Network Intrusion Detection System

## Overview

This project uses Machine Learning techniques to detect malicious network traffic and classify network activities as normal or attack traffic.

## Dataset

NSL-KDD Dataset

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features

- Data Preprocessing
- Feature Encoding
- Attack Detection
- Random Forest Classification
- Confusion Matrix Visualization
- Feature Importance Analysis
- Model Persistence using Joblib

## Installation

pip install -r requirements.txt

## Usage

Run the Jupyter notebook:

jupyter notebook

## Results

The model was trained using the NSL-KDD dataset and evaluated on unseen network traffic.
